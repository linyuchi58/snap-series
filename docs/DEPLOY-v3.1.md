# 部署 Code.gs v3.1（階段一：安全修補）

預計時間：每個試算表約 10 分鐘。
目前有 **3 個後端**，每個都要做一次：

| 後端（GAS 網址開頭） | 使用的遊戲 |
| --- | --- |
| `AKfycbz-ahKWG05g…` | 舉牌秒答樂 |
| `AKfycbzoaZ--EPlQ…` | 舉牌逆轉王 |
| `AKfycbwldbgt8JrF…` | 巔峰攀岩王、舉牌甜點大派對 |

> ⚠️ 如果其他遊戲（例如拖曳分類、泡泡拍打）也用同一個 GAS 網址，請先告訴我。v3.1 對它們是相容的，
> 唯一差別是「沒登入通行碼就建立新代碼」預設會被擋下（見步驟 4 的 `ALLOW_CREATE_WITHOUT_PASS`）。

## 步驟

1. **先備份試算表**：在 Google 雲端硬碟對試算表按右鍵 →「建立副本」。
   v3.1 會把密碼轉成雜湊值，轉換後舊版 v3.0 就無法再驗證密碼，所以要退回舊版時必須連同這份副本一起還原。
2. 開啟試算表 → 「擴充功能」→「Apps Script」。
3. 把 `Code.gs` 的內容**全部刪除**，貼上 `gas/Code.gs`（v3.1）的完整內容，按儲存。
4. 左側齒輪「專案設定」→ 最下方「指令碼屬性」→「新增指令碼屬性」：

   | 屬性 | 值 | 必填 |
   | --- | --- | --- |
   | `SUPER_ADMIN_PASS` | **一組新的**最高管理員密碼（舊密碼已出現在多份文件中，請不要沿用） | 必填 |
   | `AUTH_HUB_SPREADSHEET_ID` | 中央授權總表的 ID（就是舊版 Code.gs 第 7 行引號裡那串） | 必填 |
   | `ALLOW_CREATE_WITHOUT_PASS` | `true` | 只有舊遊戲需要「不登入也能建代碼」時才加 |
   | `REQUIRE_AUTH_FOR_RECORDS` | `true` | 等所有使用這個後端的遊戲都換成新版後再加 |

5. 回到編輯器，上方函式下拉選單選 **`setupSecurity`** → 按「執行」。
   第一次會要求授權，照畫面同意即可。執行紀錄會顯示：
   `✅ 安全設定完成：轉換管理密碼 N 筆、建立者通行碼 N 筆……`
   若出現「⚠️ 尚未設定 …」，回到步驟 4 補上。
6. 右上角「部署」→「**管理部署作業**」→ 點目前那個部署的鉛筆圖示 →「版本」選「**新版本**」→「部署」。
   ⚠️ 一定要用「管理部署作業」編輯舊的部署，**不要**按「新增部署作業」，否則網址會改變，前端就連不上了。
7. 換上 `games/` 裡對應的新版 HTML（秒答樂 v2.8.7、逆轉王 v1.2.1、攀岩王 v1.3.1、甜點 v1.1.1）。

## 部署後的 5 分鐘自我檢查

- [ ] 用教師通行碼登入，看得到自己的代碼，點代碼可以直接進入後台
- [ ] 後台看得到成績紀錄
- [ ] 改一個題目並「儲存並發布」，重新整理後還在
- [ ] 用管理密碼（而不是通行碼）也能進入同一個代碼
- [ ] 用新的最高管理員密碼可以進入任何代碼
- [ ] 跑一題、上傳成績，後台出現新紀錄
- [ ] 在瀏覽器網址列打開 `你的GAS網址?action=getRoomConfig&roomCode=你的代碼`，回傳內容裡**沒有** `roomPin`

## 出問題時

- 所有錯誤現在都會顯示原因（例如「密碼錯誤次數過多，暫停 10 分鐘」、「目前使用人數較多，請 3 秒後再試」）。
- 要退回 v3.0：「管理部署作業」把版本選回舊版本，**並且**用步驟 1 的副本還原試算表。
- 最高管理員以前用舊密碼建立的代碼，換新密碼後不會出現在「我的代碼」清單，但仍可用代碼＋新密碼直接進入。
