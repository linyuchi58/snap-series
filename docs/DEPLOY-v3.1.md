# 部署 Code.gs v3.1

四款舉牌遊戲（秒答樂、逆轉王、攀岩王、甜點派對）現在共用**同一個後端**：

| 後端 | 網址開頭 | 處理方式 |
| --- | --- | --- |
| 共用後端（原攀岩王／甜點派對） | `AKfycbwldbgt8JrF…` | **更新成 v3.1**（下面的步驟） |
| 秒答樂舊後端 | `AKfycbz-ahKWG05g…` | 不用更新，確認新版沒問題後封存 |
| 逆轉王舊後端 | `AKfycbzoaZ--EPlQ…` | 不用更新，確認新版沒問題後封存 |

舊後端裡只有測試資料，不必搬移。

共用之後：同一個代碼四款都能用；每位老師的 5 組額度四款合併計算；後台在「場次」下方標明每筆成績來自哪一款遊戲；同一班的場次編號四款接著算。

預計時間：約 10 分鐘。

## 步驟

1. **先備份試算表**：在 Google 雲端硬碟對共用後端的試算表按右鍵 →「建立副本」。
   v3.1 會把密碼轉成雜湊值，轉換後舊版 v3.0 就無法再驗證密碼，所以要退回舊版時必須連同這份副本一起還原。
2. 開啟這個試算表 → 「擴充功能」→「Apps Script」。
3. 把 `Code.gs` 的內容**全部刪除**，貼上 `gas/Code.gs`（v3.1）的完整內容，按儲存。
4. 左側齒輪「專案設定」→ 最下方「指令碼屬性」→「新增指令碼屬性」：

   | 屬性 | 值 |
   | --- | --- |
   | `SUPER_ADMIN_PASS` | **一組新的**最高管理員密碼（舊密碼已出現在多份文件中，請不要沿用） |
   | `AUTH_HUB_SPREADSHEET_ID` | 中央授權總表的 ID（就是舊版 Code.gs 第 7 行引號裡那串） |

5. 回到編輯器，上方函式下拉選單選 **`setupSecurity`** → 按「執行」。
   第一次會要求授權，照畫面同意即可。執行紀錄會顯示：
   `✅ 安全設定完成：轉換管理密碼 N 筆、建立者通行碼 N 筆……`
   若出現「⚠️ 尚未設定 …」，回到步驟 4 補上。
6. 右上角「部署」→「**管理部署作業**」→ 點目前那個部署的鉛筆圖示 →「版本」選「**新版本**」→「部署」。
   ⚠️ 一定要用「管理部署作業」編輯舊的部署，**不要**按「新增部署作業」，否則網址會改變，前端就連不上了。
7. 換上 `games/` 裡的四個新版 HTML（秒答樂 v2.9.0、逆轉王 v1.2.3、攀岩王 v1.3.3、甜點派對 v1.1.3）。
   如果您的瀏覽器裡存著秒答樂或逆轉王的舊後端網址，新版會自動換成共用網址。

## 部署後的 5 分鐘自我檢查

- [ ] 用教師通行碼登入，看得到自己的代碼，點代碼可以直接進入後台
- [ ] 在任一款建立的代碼，另外三款輸入同一個代碼也能載入題庫
- [ ] 改一個題目並「儲存並發布」，重新整理後還在
- [ ] 用管理密碼（而不是通行碼）也能進入同一個代碼
- [ ] 用新的最高管理員密碼可以進入任何代碼
- [ ] 跑一題、上傳成績，後台出現新紀錄，「場次」下方有遊戲名稱
- [ ] 在瀏覽器網址列打開 `共用GAS網址?action=getRoomConfig&roomCode=你的代碼`，回傳內容裡**沒有** `roomPin`
- [ ] 在教室實際掃一輪紙卡，辨識和以前一樣好

全部沒問題之後，到秒答樂與逆轉王的舊 Apps Script →「部署」→「管理部署作業」→「封存」，停用舊網址。

## 出問題時

- 所有錯誤現在都會顯示原因（例如「密碼錯誤次數過多，暫停 10 分鐘」、「目前使用人數較多，請 3 秒後再試」）。
- 要退回 v3.0：「管理部署作業」把版本選回舊版本，**並且**用步驟 1 的副本還原試算表。
- 最高管理員以前用舊密碼建立的代碼，換新密碼後不會出現在「我的代碼」清單，但仍可用代碼＋新密碼直接進入。
- `importFromOtherSpreadsheet()` 可以把其他試算表的代碼與成績搬進來（這次用不到，使用方式寫在 Code.gs 該函式的註解裡）。
